# My online CV.

## What to do to run the site locally ?

`npm install -g gulp-cli`

`npm install`

`gulp`

To ***publish*** with the help of github pages use `npm run deploy`

### Technologies used

- HTML/HTML5,
- SASS,
- Gulp,
- NPM Scripts,
- Figma -> [With extension](https://pdkit.co)
